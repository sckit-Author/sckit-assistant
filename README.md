# sckit-assistant

Official assistant documentationas a user manual and as reference material for AI assistants or local language models that provide guidance for sckit users.

## Repository Structure

```text
sckit-assistant/
├── README.md
├── manifest.json
└── assistant/
    └── sckit_assistant.md
```

## Assistant Document

The main assistant document is:

```text
assistant/sckit_assistant.md
```

This file is intended to provide structured documentation for sckit, including:

- software overview
- command hierarchy
- command-line parameters
- analysis workflows
- input requirements
- output files
- usage examples
- troubleshooting
- error messages
- interpretation of results

The document can also be used as reference material for AI assistants or local language models that provide guidance for sckit users.

## sckit Assistant Commands

The assistant module uses explicit subcommands.

### Export

Export the current assistant Markdown document:

```bash
sckit assistant export -o /path/to/output
```

The exported file will be:

```text
/path/to/output/sckit_assistant.md
```
